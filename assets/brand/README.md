# Touchstone brand assets

The PNG artwork in this directory is the README hero pair for Touchstone. It
represents the audit harness as a path through three gates:
the return path represents an approved merge, while the gold endpoint denotes
a parked change that requires a person.

| Asset | Intended use |
| --- | --- |
| `touchstone-readme-hero.png` | Light-mode repository README hero |
| `touchstone-readme-hero-dark.png` | Dark-mode repository README hero |

## Palette

- Rice: `#F8F5EE`
- Moss: `#66795E`
- Deep forest: `#2E4034`
- Kerria gold: restrained park/witness accent

Use the assets through the `<picture>` element in the repository README. Keep
their composition paired: only surface, contrast, and text colour vary between
themes. The graphic is an abstract system mark, not a live status diagram or a
literal stone. It carries no runtime status, project identity, or configuration.
